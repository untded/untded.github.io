# 07 — JSON-LD context and interop examples

vocab-bsp's strongest artifact is its mappings/: proof that UNTP/UNVTD
credentials can re-point `@context` at their vocabulary. We publish the
TDED context from our mandate position — no federation, just clean
consumption of our terms.

## Work

- Serve the generated context at a stable URL (`/ns/untded-context.jsonld`
  or equivalent) — already generated by the dataset export; wire the
  route and cache headers within GitHub Pages constraints.
- Docs page (03 corpus): `context.mdx` — what the context covers, how to
  reference TDED elements from JSON-LD, versioning policy (context pinned
  per edition).
- One worked example each for the audiences we actually have:
  - a UN/EDIFACT-adjacent consumer mapping EDED entries to TDED terms;
  - a DPP/UNTP-flavored example citing data elements by IRI in a product
    passport payload (interop example, not an endorsement of vocab-bsp).
- Version the context IRI per edition so consumers can pin.

## Verification

- Contract: context URL serves the generated file byte-identical to the
  dataset export; docs example snippets are valid JSON-LD (parse test in
  the spec suite with the real context).

## Beats

Their context serves their invented BSP reconciliation; ours serves the
directory itself, generated from the SSOT, under the organization the
resolution names.
