# 22 — The 1993 reconstruction: the directory as it was

The 2005 edition's change tags and old names carry the 1993 directory
inside them. Nobody has ever made it visible. Elements with change_tag
"add" didn't exist in 1993; elements with old_name had a different
name; retired elements existed then. The reconstruction is derivable
entirely from our existing data — no new source needed.

      old_name where present → the 1993 name).
- [x] Website `/1993` — the directory as it stood before the 2005

      as they were, with a "what changed" link per element to its
      current page. Plain card language, ledger aesthetic.
- [x] Element pages: for elements with old_name, a "1993 view" line

- [x] Contracts: /1993 built; count matches (1504 − added = 1043);

## Beats

Their extraction has no historical dimension at all; ours reconstructs
the previous edition from the current one's own metadata — a view only
the mandated registry can assert.
