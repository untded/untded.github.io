The publication's foreword states the relationship plainly: the 2005
revision of the TDED is "fully consistent with the set of UN/EDIFACT
directories supporting electronic data interchange, especially with the
EDIFACT Data Element Directory (EDED)". This page makes that claim
checkable against our data.

## The join

Element pages show an **EDED chip** when the element's tag appears in the
UN/EDIFACT **D.05B** segments directory (a mirror of the official UNECE
publication). The chip shows the EDED representation (`type..maxlength`)
next to ours:

- **aligned** — charset and maximum length corroborate;
- **representation differs** — the two printed forms disagree; the chip
  links to the corresponding row below.

## Method and limits

- The mirror lists every data element **used in segments**, with name,
  description, type and max length; elements not referenced by any
  segment do not appear, so absence of a chip is informational, not a
  mismatch.
- The join is by tag number. The cross-check
  (`bin/crosscheck-edifact` in the dataset) additionally compares names
  and descriptions with a normalized similarity threshold; its full
  report lives in the dataset repository.
- Representation disagreements are printed as-is on both sides; none are
  silently reconciled.

## Code lists (UNCL)

The foreword's claim covers the UN Codes Library as well: Volume II of
the publication is the code-list volume (part of UNCL of the UN/EDIFACT
directory). Element pages show a **UNCL D05B chip** when the element is
code-qualified in the D.05B code list, with the number of code values —
for example [3055](/elements/3055) carries 316 values.

- **Coverage:** 256 active elements of this directory are code-qualified
  in the D.05B UNCL, carrying 10,104 code values between them. The
  machine-readable list is [`/data/uncl-coverage.json`](/data/uncl-coverage.json).
- **Method:** tag join against the code-list mirror in the dataset
  repository (`bin/join-uncl`); the mirror carries the code values with
  their short names. Eleven D05B-coded identifiers (3405, 3493, 4071,
  5501, 6029, 6415, 9155, 9161, 9601, 9633, 9645) are not elements of
  this directory at all and are skipped.
- **Limits:** the mirror does not carry the full UNCL descriptions, so
  the bracket cross-references that section 4.1.5 of the publication
  describes (a qualifier code whose combined meaning equals a specific
  TDED element names that element's tag) are not yet derivable; that
  needs the official UNCL file. And the vintage caveat applies as above
  — this edition was built on D.02A, D05B is the cross-check vintage.
