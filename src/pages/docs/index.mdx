The documentation corpus covers how the registry is built and how to consume it:

- [Ontology guide](/docs/ontology) — the RDF model of the directory, with examples.
- [UN/EDIFACT alignment](/docs/alignment-edifact) — how the directory and the D.05B directories corroborate, element by element.
- [Vocabulary register](/docs/vocabulary-register) — the external vocabularies and standards the directory lives among.
- [Provenance](/docs/provenance) — how the digitization was made and verified.
- [JSON-LD context](/docs/context) — consuming TDED terms from JSON-LD.
- [Contributing](/docs/contributing) — requesting corrections and new editions.

The registry pages themselves carry the data: the [directory](/elements), the [ontology](/ontology), the [edition ledger](/ledger), the [bridges map](/bridges) and the [UN layout key reconstruction](/unlk).
